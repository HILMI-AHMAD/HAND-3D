
# HAND 3D — Real-Time Hand Tracking

HAND 3D adalah proyek berbasis Python yang menggunakan teknologi Computer Vision untuk mendeteksi gerakan tangan secara real-time melalui kamera.

## Fitur
- Deteksi tangan menggunakan MediaPipe.
- Pelacakan landmark tangan secara real-time.
- Visualisasi efek 2D dan 3D.
- Berbagai pilihan filter visual.
- Kontrol efek menggunakan gerakan tangan.

## Teknologi
- Python 3.12
- OpenCV
- MediaPipe
- NumPy

## Instalasi

Clone repository:

```bash
git clone https://github.com/USERNAME/HAND-3D.git
cd HAND-3D
```

Install library:

```bash
pip install -r requirements.txt
```

## Menjalankan Program

```bash
python hand_tracking.py
```

## Kontrol
- `Q` : Keluar dari program.
- `N` : Ganti filter berikutnya.
- `P` : Ganti filter sebelumnya.
- `C` : Ganti mode 2D dan 3D.
